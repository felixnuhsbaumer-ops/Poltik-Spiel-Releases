# Politik-Spiel – Downloads

Politik-Simulator Österreich: Regiere als Bundeskanzler:in, halte deine Koalition zusammen und gewinne die Wahl.

Dieses Repository enthält nur die fertigen Programme, keinen Quellcode.

**Herunterladen:** unter [Releases](../../releases/latest) die ZIP für deinen Rechner wählen:
- `…-x64.zip` für normale Windows-PCs,
- `…-arm64.zip` für Windows-Rechner mit ARM-Prozessor.

Entpacken (am besten auf den Desktop oder nach „Dokumente“), `Politik-Spiel.exe` doppelklicken – keine Installation nötig.

**Updates:** Ab Version 1.1 sucht das Spiel beim Start selbst nach neuen Versionen und aktualisiert sich per Klick. Spielstände bleiben erhalten.
